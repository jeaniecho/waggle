# Task 002 — Draggable Dog

**Status: Complete**

## Goal

Allow the user to drag the dog around the screen.

## Files Likely Involved

- `Overlay/DogOverlayView.swift`
- `Overlay/DogOverlayWindowController.swift`
- `Overlay/OverlayPositionStore.swift`
- `Dog/DogViewModel.swift`
- `Settings/SettingsStore.swift`

## Requirements

- Dog can be dragged smoothly.
- Overlay window follows drag.
- Dog enters dragging state during drag.
- Position persists after drag ends.
- Position restores after relaunch.

## Acceptance Criteria

- User can drag dog.
- Dog position updates smoothly.
- Position is saved.
- Relaunch restores saved position.
