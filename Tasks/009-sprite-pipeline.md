# Task 009 — Sprite Pipeline

## Goal

Prepare the app to use pixel-art dog sprites.

## Requirements

- DogSpriteView can switch between placeholder and image assets.
- Asset naming convention documented.
- Rendering avoids blurry scaling where practical.

## Suggested Asset Names

- `dog_idle_0`
- `dog_idle_1`
- `dog_tail_wag_0`
- `dog_tail_wag_1`
- `dog_typing_0`
- `dog_typing_1`
- `dog_stretch_0`
- `dog_sleep_0`
- `dog_celebrate_0`

## Acceptance Criteria

- Placeholder remains functional.
- Adding PNG assets later requires minimal code changes.
