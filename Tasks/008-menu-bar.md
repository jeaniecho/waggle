# Task 008 — Menu Bar Controls

## Goal

Add menu bar controls for Waggle.

## Files Likely Involved

- `MenuBar/MenuBarController.swift`
- `MenuBar/MenuBarAction.swift`
- `App/AppEnvironment.swift`

## Requirements

- Menu bar item appears.
- Start/stop Pomodoro.
- Reset stretch timer.
- Show/hide overlay.
- Open Accessibility settings.
- Quit.

## Acceptance Criteria

- User can control app from menu bar.
- User can quit reliably.
- Menu actions call manager methods, not duplicated logic.
