# Task 007 — Pomodoro Mode

## Goal

Add Pomodoro focus/break mode.

## Files Likely Involved

- `Productivity/PomodoroManager.swift`
- `Productivity/PomodoroState.swift`
- `Dog/DogViewModel.swift`
- `MenuBar/MenuBarController.swift`
- `Settings/AppSettings.swift`

## Requirements

- Focus duration default: 25 minutes.
- Break duration default: 5 minutes.
- Start/stop/reset.
- Dog state changes during focus and break.
- Settings persist.

## Acceptance Criteria

- User can start Pomodoro.
- Dog enters focus behavior.
- Break starts after focus.
- Dog enters break behavior.
- User can stop/reset.
