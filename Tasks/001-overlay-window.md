# Task 001 — Transparent Overlay Window

**Status: Complete**

## Goal

Create a transparent always-on-top window that hosts SwiftUI content.

## Files Likely Involved

- `Overlay/DogOverlayWindow.swift`
- `Overlay/DogOverlayWindowController.swift`
- `Overlay/DogOverlayView.swift`
- `App/AppDelegate.swift`
- `App/AppEnvironment.swift`

## Requirements

- Borderless transparent window.
- Floating above normal windows.
- Hosts SwiftUI dog view.
- Shows placeholder dog.
- Window is sized around dog content.
- App can quit cleanly.

## Acceptance Criteria

- App launches.
- Transparent overlay appears.
- Placeholder dog is visible.
- Overlay remains above normal windows.
- No unnecessary standard window appears.

## Verification

Run app from Xcode and manually confirm overlay behavior.
