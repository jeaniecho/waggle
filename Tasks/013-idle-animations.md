# Task 013 — Idle Animations

## Goal
Make the resting dog feel alive (keeps the current placeholder design — no real
sprite art).

## Behaviours
- Occasional blink.
- Subtle breathing (slow vertical scale) when idle.

## Requirements
- Only when idle (not dragging/typing/stretch/Pomodoro reactions).
- Cheap; no constant high-frequency redraw when nothing is happening.

## Acceptance Criteria
- The idle dog blinks/breathes naturally without interfering with other states.
