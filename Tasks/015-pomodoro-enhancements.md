# Task 015 — Pomodoro Enhancements

**Status: Partial** — long-break cycles and in-set counting work; a persisted
"today" count is not yet displayed.

## Goal
Make Pomodoro feel complete.

## Requirements
- Count completed focus sessions.
- After N sessions (default 4), take a long break (default 15 min) instead of a
  short one; then reset the count.
- Durations + N configurable and persisted.
- Menu/Settings can show today's completed count.

## Acceptance Criteria
- Sessions count up; every Nth break is the long break; values persist.
