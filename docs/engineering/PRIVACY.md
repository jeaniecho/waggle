# Privacy Policy for Development

Waggle is local-first.

## Data Waggle May Store

- Dog position
- Stretch reminder enabled/disabled
- Stretch interval
- Pomodoro focus duration
- Pomodoro break duration

## Data Waggle Must Not Store

- Typed text
- Key names
- Keyboard history
- Cursor paths
- App names
- Window titles
- Screenshots
- User documents
- Behavior analytics

## Keyboard Monitoring

Keyboard monitoring exists only to detect that typing occurred. It must trigger a generic dog animation and discard the event.

## Cursor Monitoring

Cursor monitoring exists only to calculate relative direction and proximity. It must not be stored as history.

## Networking

No network access is needed for MVP.
