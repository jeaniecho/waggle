# Menu Bar Specification

## Goal

Give the user basic controls without requiring a normal app window.

## Menu Items

- Start Pomodoro
- Stop Pomodoro
- Reset Stretch Timer
- Show Waggle
- Hide Waggle
- Open Accessibility Settings
- Quit

## Behavior

The menu bar should:
- Reflect current Pomodoro availability where practical.
- Control overlay visibility.
- Provide a clear quit action.

## Acceptance Criteria

- Menu bar item appears.
- User can quit app.
- User can show/hide dog.
- User can start/stop Pomodoro after Pomodoro manager exists.
